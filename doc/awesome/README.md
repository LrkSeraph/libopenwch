# Doxygen Awesome

Vendored theme assets from [Doxygen Awesome](https://github.com/jothepro/doxygen-awesome-css),
release v2.5.0 (commit 46483f1e5a70ffb9ecd3b82d0a1cd1b24edf13da).

These files are kept verbatim so that the API documentation does not depend on
a network fetch or a system-wide theme installation.  Doxygen Awesome is
licensed under the MIT licence; see `LICENSE` in this directory.

The project's own colour overrides live in
`../templates/libopenwch-custom.css`; they are not part of Doxygen Awesome.
